How It Works

How do you connect an AI agent to Ceptory MCP?

Connecting takes under two minutes: add the hosted MCP URL to your client, approve access in your browser over OAuth 2.1 with PKCE, and verify your workspace with get_account.

  1. 1

    Add the MCP URL

    Paste https://mcp.ceptory.com/mcp into Claude Code, Claude Desktop, Cursor, VS Code, Codex, Gemini CLI, or Windsurf. No API key required for OAuth clients.

  2. 2

    Approve in your browser

    Your client discovers OAuth 2.1 automatically via .well-known/oauth-authorization-server and opens ceptory.com so you click Allow. Headless agents can use a Bearer token from /dashboard/mcp.

  3. 3

    Pair with the 11 Agent Skills

    Run npx skills add whyashthakker/video-intelligence so your agent knows every camera workflow schema, alert verification rule, RTSP template, and report format automatically.

Client Configuration

How do you configure Ceptory MCP in each AI client?

Every MCP client below works with Streamable HTTP (MCP 2026-07-28, backwards-compatible with 2025 clients). Use the ceptory-mcp stdio bridge when you also want one-step local upload_video_file and image_path helpers.

Claude Code

Run in your terminal, then type /mcp in Claude Code and choose Authenticate to approve in your browser.

claude mcp add --transport http ceptory https://mcp.ceptory.com/mcp

Claude Desktop & claude.ai

In Connectors UI: Settings → Connectors → Add custom connector with https://mcp.ceptory.com/mcp. Or use stdio for local files:

{
  "mcpServers": {
    "ceptory": {
      "command": "npx",
      "args": ["-y", "ceptory-mcp"],
      "env": { "CEPTORY_TOKEN": "<token>" }
    }
  }
}

Cursor

Add to ~/.cursor/mcp.json or project .cursor/mcp.json. Cursor prompts browser OAuth sign-in automatically.

{
  "mcpServers": {
    "ceptory": { "url": "https://mcp.ceptory.com/mcp" }
  }
}

VS Code (GitHub Copilot)

Add to .vscode/mcp.json or run MCP: Add Server from the Command Palette.

{
  "servers": {
    "ceptory": { "type": "http", "url": "https://mcp.ceptory.com/mcp" }
  }
}

OpenAI Codex CLI

Run the add + login commands for browser OAuth, or configure npx -y ceptory-mcp in ~/.codex/config.toml.

codex mcp add ceptory --url https://mcp.ceptory.com/mcp
codex mcp login ceptory

Gemini CLI

Add to ~/.gemini/settings.json, then run /mcp auth ceptory inside Gemini CLI.

{
  "mcpServers": {
    "ceptory": { "httpUrl": "https://mcp.ceptory.com/mcp" }
  }
}

Windsurf

Add to ~/.codeium/windsurf/mcp_config.json. Windsurf initiates browser OAuth automatically.

{
  "mcpServers": {
    "ceptory": { "serverUrl": "https://mcp.ceptory.com/mcp" }
  }
}

OpenAI Agents SDK, LangChain, Mastra & n8n

Security, Governance & Pricing

How does Ceptory MCP enforce permissions and billing?

MCP calls execute in-process against the exact same API handlers as the Ceptory web dashboard and desktop app—so RBAC, rate limits, and prepaid usage match identically.

Browser OAuth 2.1 + instant revocation: Agents never see your password, only a hashed session token is stored, and revoking an agent at /dashboard/mcp cuts access immediately.
Workspace RBAC enforced server-side: VIEWER members remain strictly read-only (403 on writes); only editors/admins can create cameras or modify rules.
Destructive tool annotations: Every delete tool declares destructiveHint: true so compliant clients confirm with a human before deleting cameras, videos, or people.
Transparent pay-as-you-go usage: Connecting MCP is free. Workspaces start with free indexing minutes, then metered indexing ($0.042/min + $0.0015/min infra) and search ($4/1,000 queries) at ceptory.com/pricing.

FAQ

Ceptory MCP Server questions, answered

What is the Ceptory MCP server URL and protocol version?

The hosted Streamable HTTP endpoint is https://mcp.ceptory.com/mcp, supporting MCP 2026-07-28 with backwards compatibility for 2025-era clients. For stdio-only clients or one-step local file uploads, run CEPTORY_TOKEN=<token> npx -y ceptory-mcp.

How does authentication work on Ceptory MCP?

Interactive MCP clients discover OAuth 2.1 with PKCE and dynamic client registration directly from https://mcp.ceptory.com/mcp and open ceptory.com in your browser to approve. Headless agents, CI pipelines, and the stdio bridge can authenticate with a Bearer token created at https://www.ceptory.com/dashboard/mcp.

What can an AI agent do through Ceptory MCP?

An approved agent can ingest and search recorded video in natural language, ask grounded questions about clips, configure all 10 live camera workflows (PPE, person down, fire and hazards, intrusion, face access, loitering, unattended bags, crowd limit, illegal parking, rider helmets), manage people and license plate lists, inspect and resolve alerts with annotated photos, trace cross-camera journeys, and run individual AI detection engines.

Which MCP clients and agent frameworks are supported?

Ceptory MCP works with any standard MCP client, including Claude Code, Claude Desktop, claude.ai, Cursor, VS Code (GitHub Copilot), OpenAI Codex CLI, Gemini CLI, Windsurf, Antigravity, OpenAI Agents SDK, LangChain, Mastra, and n8n.

How are workspace permissions, destructive tools, and billing enforced?

Every MCP tool invokes the same server route handler as the Ceptory dashboard using the approving user's workspace and role. Viewer accounts remain read-only, delete tools are annotated destructive so agents confirm before running them, and paid actions draw from the workspace's free indexing allowance and prepaid balance.

How do I revoke an MCP agent's access?

Open https://www.ceptory.com/dashboard/mcp and revoke the connected agent or token. Access stops immediately. Browser OAuth sessions also expire automatically after 30 days.
