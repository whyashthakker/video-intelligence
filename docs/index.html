Live MCP Server

Connect the MCP server in under two minutes

Pair these skills with a hosted Streamable HTTP MCP server (https://mcp.ceptory.com/mcp) or local-file stdio bridge (npx -y ceptory-mcp). See full client instructions at ceptory.com/mcp.

Claude Code

Run in your terminal, then type /mcp and approve in your browser.

claude mcp add --transport http video-intel https://mcp.ceptory.com/mcp

Cursor (~/.cursor/mcp.json)

Add the server URL — Cursor handles OAuth 2.1 browser sign-in automatically.

{
  "mcpServers": {
    "video-intel": { "url": "https://mcp.ceptory.com/mcp" }
  }
}

VS Code (.vscode/mcp.json)

Works directly in GitHub Copilot agent mode with OAuth discovery.

{
  "servers": {
    "video-intel": { "type": "http", "url": "https://mcp.ceptory.com/mcp" }
  }
}

Claude Desktop / Local Video Uploads

Use the stdio bridge to unlock one-step upload_video_file and image_path.

CEPTORY_TOKEN=<token> npx -y ceptory-mcp
